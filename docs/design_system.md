# Design System

This document outlines the visual tokens, UI rules, and component specs for ShopGPT 2.0.

## Typography
- **Font Family**: Inter, sans-serif
- **Font Sizes**: 
  - clamp(1.75rem, 4vw, 2.5rem) (h1)
  - clamp(1.4rem, 3vw, 2rem) (h2)
  - clamp(1.15rem, 2.5vw, 1.4rem) (h3)
  - 0.925rem (body / button text)
  - 0.8rem (small text / tags)

## Color Palette (Dark Theme Tokens)
- **Background Base**: `#0a0a0f` (`--bg-base`)
- **Background Surface**: `#111118` (`--bg-surface`)
- **Background Card**: `#16161f` (`--bg-card`)
- **Primary / Purple**: `#7c3aed` (`--primary`)
- **Accent / Cyan**: `#06b6d4` (`--accent`)
- **Success / Green**: `#10b981` (`--success`)
- **Warning / Orange**: `#f59e0b` (`--warning`)
- **Danger / Red**: `#ef4444` (`--danger`)
- **Text Light**: `#f1f5f9` (`--text-light`)
- **Text Muted**: `#94a3b8` (`--text-muted`)

## Spacing Scale
- `--space-1`: `0.25rem`
- `--space-2`: `0.5rem`
- `--space-3`: `0.75rem`
- `--space-4`: `1rem`
- `--space-5`: `1.25rem`
- `--space-6`: `1.5rem`
- `--space-8`: `2rem`
- `--space-10`: `2.5rem`
- `--space-12`: `3rem`
- `--space-16`: `4rem`
- `--space-20`: `5rem`

## Light Theme Tokens (Switched via Cookie)
- **Background Base**: `#f8fafc`
- **Background Surface**: `#ffffff`
- **Background Card**: `#f1f5f9`
- **Text Light**: `#0f172a`
- **Text Muted**: `#475569`
